Setup & Installation

How to use JP Dev Tools products.

Cheat Sheets

Download the ZIP from Gumroad. Extract anywhere. Open .md files in:

  • VS Code (built-in Markdown preview: Ctrl+Shift+V)
  • Obsidian (drag into vault)
  • Any text editor
  • GitHub (renders Markdown natively)

Notion Templates

  1. Extract the ZIP
  2. Open Notion → Settings → Import → Markdown & CSV
  3. Select the template files
  4. Templates appear in your workspace

Customization

All products are designed to be customized. Markdown files can be edited in any text editor. Notion templates can be modified after import.

Adding Your Own Content

Docker Cheat Sheet — Dockerfile, Compose & Security (2026)

By Jamie Phillips · July 2026 · JP Dev Tools

Docker in 2026

Containers are default. But most Dockerfiles are inefficient — large images, slow builds, security holes. This cheat sheet fixes that.

Multi-Stage Build Pattern

FROM node:20 AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-slim
COPY --from=build /app/dist ./dist
CMD ["node", "dist/index.js"]
Result: 90% smaller image.

Security Essentials

  • Never run as root (use USER directive)
  • Pin base image versions (not :latest)
  • Use .dockerignore
  • Scan with `docker scout`
  • Read-only filesystem where possible

Git Beyond Add-Commit-Push

Most developers use 5 git commands. There are hundreds. The gap between 'I know git' and 'I really know git' is worth 10x productivity.

Commands You Should Know

  • `git reflog` — recover 'lost' commits
  • `git bisect` — binary search for bugs
  • `git stash -p` — stash specific changes
  • `git cherry-pick` — grab commits from other branches
  • `git rebase -i` — rewrite history cleanly
  • `git worktree` — work on multiple branches simultaneously

Pro Tip: Git Aliases

git config --global alias.lg 'log --oneline --graph --all'
git config --global alias.unstage 'reset HEAD --'
git config --global alias.last 'log -1 HEAD'
